# GenAI Case Studies

Canonical public Markdown collection for reviewed GenAI consulting, PoC delivery, and applied AI engineering case studies.

This repository is the text-first companion to the public showcase site: <https://hwan96-ai.github.io/genai-case-study-showcase/>. It is meant for readers who want the case-study copy in a plain Markdown format that can be reviewed, linked, searched, or reused in interview preparation.

## Scope

- Public-safe case-study narratives only
- Conservative role and outcome wording
- No private logs, internal endpoints, credentials, raw customer material, or unapproved customer names
- Korean-first case copy, with selected English supporting examples

## Public Safety Rules

- Do not add non-public system identifiers, non-public links, confidential operational material, access material, personal data, or unapproved customer names.
- Do not invent metrics or outcomes. A07 has no public CTR, conversion, or revenue claim. A08 has no public traffic, accuracy, or consultation-count claim.
- Approved public names are intentionally narrow: Sapie Reco, idus(backpackr), Yeonsung University, SAPiE, Kakao i, and the A08 service URL <https://yeonsung.sapie.ai/>.
- Supporting proofs demonstrate implementation and delivery literacy. They should not be reframed as standalone business-impact claims.
