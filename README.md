## 정직성 · 범위

- **공개명 정리:** 2026-06-28부터 공개 제목·링크·파일명은 설명형 이름만 사용합니다. 내부 추적 ID는 PUBLIC 산출물에 표시하지 않으며, 세부 매핑은 비공개 SSOT에서만 관리합니다.
- **수치를 지어내지 않습니다.** 보유하지 않은 정량 성과(전환율·CTR·상담 건수 등)는 주장하지 않습니다.
- **역할 경계를 명시합니다.** 총괄/리드한 부분과 직접 구현한 부분, 팀 작업을 구분합니다.
- **고객 소스 코드는 비공개입니다.** 공개 근거는 출시 보도자료·운영 URL·본인 보유 공개 레포로 한정합니다.
- 공개 이름·URL은 현재 승인 메타데이터가 있는 범위에서만 사용합니다. 교육기관 조직 표시명은 승인 갱신 전까지 `공개 교육기관`으로 익명화합니다.

> 언어: 현재 주요 케이스와 보조 기술 증명은 모두 한국어입니다. 영어판은 별도 산출물로 추가할 때 이 안내를 갱신합니다.
